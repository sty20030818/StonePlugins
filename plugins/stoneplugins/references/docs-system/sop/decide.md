# 形成并记录决定

## 适用与依据

需要澄清目标、追问取舍，或把讨论结果转为有效决定。 共同权限、状态与版本规则见[共同约定](../conventions.md)。

## 读取

已确认目标、方案比较、相关约束及受影响资料。

## 操作

1. 查明哪些选择已经确认、哪些仍未决，优先调查可从项目发现的事实。
2. 围绕会改变方向的分歧追问并给出推荐及适用边界；依[共同约定](../conventions.md)处理授权和关键变更。
3. 明确实际确认的范围。批准方向不代表尚未讨论的技术细节、额外工作或发布承诺也已批准。
4. 将有效决定写回该内容的所有者；重要且长期需要解释的取舍才新增 decisions 记录，并说明理由、代价和替代关系。
5. 未决问题留在所属计划或研究，不用猜测补成已确认事实。

## 产出与完成

独立决定记录注明标识、日期、生效情况、选择依据与后果，需要时关联被替代记录。完成意味着决定、依据、影响与未决范围可从仓库找到。后续按需要进入 [story](story.md)、[plan](plan.md) 或已有任务。
