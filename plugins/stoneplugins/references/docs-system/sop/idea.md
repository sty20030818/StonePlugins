# 记录与处理想法

## 适用与依据

有问题、灵感或改进设想，但还没有形成执行承诺。 共同权限、状态与版本规则见[共同约定](../conventions.md)。

## 读取

产品目标、已有想法、相关任务与研究。

## 操作

1. 先检查是否已有同一问题的记录或任务；已有任务直接关联，避免生成另一份待办。
2. 记录想解决的问题、期待的价值和必要背景，明确哪些是事实、假设和待讨论问题。
3. 信息不足时提出需要调查或澄清的问题；涉及不同方向时交给 [compare](compare.md)，需要取舍时交给 [decide](decide.md)。
4. 已采纳、放弃或实现后，从待处理区移出，必要的决定和理由进入其内容所有者，保留接收阶段或任务的链接。

## 产出与完成

写入项目想法待办，按需链接相关讨论、研究或已有任务。新想法记录完成意味着内容可理解且无重复承诺；处理已有想法时再补明确去向。记录想法本身不自动批准实施。
