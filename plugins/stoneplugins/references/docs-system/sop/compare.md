# 调研与比较方案

## 适用与依据

存在会影响结果的真实选择，需要证据支持。 共同权限、状态与版本规则见[共同约定](../conventions.md)。

## 读取

问题、目标、约束、当前规格/架构、已有决定和研究。

## 操作

1. 明确要回答的问题、比较范围和会改变选择的标准，先查现有实现与既有决定。
2. 围绕同一个问题查证一手资料；需要实验时记录假设、方法、对象、环境和实际观察。
3. 比较真正可行且差异会影响选择的方案，说明收益、成本、限制与不确定性，不制造陪衬选项。
4. 分别标注来源事实、实验观察、推断和建议，给出推荐及什么证据会改变推荐。

## 产出与完成

结果进入同一问题的研究记录，复用已有文件，并记录查阅日期、来源、建议和待决问题。完成意味着比较有可核对依据、关键未知已列出；建议需经 [decide](decide.md) 才能成为已确认决定。
