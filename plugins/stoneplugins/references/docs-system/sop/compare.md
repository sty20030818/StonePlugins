# 调研与比较方案

## 适用与读取

存在会改变结果的真实选择，需要依据支持。读取问题、目标、约束、当前规格/架构及相关决定和研究；共用规则见[共同约定](../conventions.md)。

## 操作

1. 明确比较问题、范围和判断标准，先查已有实现与已确认选择。
2. 围绕同一问题调查一手资料；需要实验时记录假设、方法和实际观察，材料按 [verify](verify.md)的必要程度保存。
3. 比较可行且差异有意义的方案，说明收益、成本、限制和关键未知，不制造陪衬选项。
4. 区分来源事实、观察、推断与建议，给出推荐及会改变推荐的条件；未确认时不写成决定。

## 输出结构与示例

复用同一问题的研究记录，按需保留：

```markdown
# <比较的问题>

## 目标与约束
<要回答什么、判断标准与已有决定。>

## 事实与来源
<查阅日期、资料位置及相关事实；实验注明对象和方法。>

## 选项与取舍
<可行方案、差异、成本和限制；适合比较时使用表格。>

## 推荐与未决项
<推荐、理由、适用边界和仍需确认的选择。>
```

## 完成判断

比较有可核对依据，推荐和关键未知明确。需要形成有效决定时按 [decide](decide.md)确认，不自动承诺开发。
