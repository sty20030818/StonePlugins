# Linear

将项目文档中的成果与进展展示到 Linear，并维护适用的原生协作信息。先读项目入口、采用的 Linear 指南及[共同约定](../../tools/stonedocs/rules/docs/conventions.md)；缺少本地适配说明时使用同包[固定操作指南](../../references/linear.md)，来源在其文件头。项目明确规则与差异优先，不自动重组已有看板。

## 读取与接续

核对本次是讨论、只读查询还是已授权写入，确定项目根、所属 Goal/Phase/Task、实际状态、标准与证据。通过[配套 CLI 用法](../../references/cli.md)定位同包工具，按实际 help 使用对象读取；没有 CLI 可读项目原文，不自动安装或用作者模式绕过故障。

先沿本项目已有映射读取远端 UUID，再由当前连接器核对 Workspace、Team 和本次对象；同名、相同 V1/T0001 不代表同一项目。工具声明不代表调用成功；缺少操作时说明具体缺口，继续不依赖它的已授权部分，不绕 token 或私人浏览器补能力。

## 操作适配

默认 Goal 用 Team 总览文档及 Project 标签表达，Phase 用 Project，Task 用 Issue；具体内容、最短步骤、状态对应及迁移安排由固定指南维护，不在本技能另写一套 SOP。总览显示带来源的判断和独立验收入口，不能由卡片完成率自动结束 Goal。

外部写入按现有授权的精确目标与字段执行；连接成功或技能触发不增加权限。保留人工负责人、优先级、排期和关系，分别核对创建、更新与读回。响应未知先查原身份，部分成功只接续未完成对象，不重复创建；新编号、URL 以实际返回保存，不预填映射或维护第二份任务状态。

plan、task、verify、review 的文档成果可作为本次输入，无须先调用这些技能；本技能也不要求调用它们来写回状态。讨论或只读请求止于方案与观察，完成本地任务和操作 Linear 分别判断。

## 输出

说明实际项目/Team、对象及来源、已执行修改与独立读回、失败和未完成去向。按交付对象把结果写回项目任务或验收位置；不把工具可用、草案形成或静态检查写成看板已完成，不因同步展示自动归档父级。
