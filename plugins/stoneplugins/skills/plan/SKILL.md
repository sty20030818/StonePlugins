# Plan

根据已确认目标规划或调整成果阶段。先读取项目入口、[共同约定](../../references/docs-system/conventions.md)与[阶段计划 SOP](../../references/docs-system/sop/plan.md)；输入、操作、写回与完成判断由这些文档维护。填写结构见[计划输出结构与示例](../../references/docs-system/sop/plan.md#输出结构与示例)，资源版本见[固定快照清单](../../references/docs-system/source.json)。

## 项目读取

沿项目入口读取产品目标、roadmap、已有阶段、适用规则和已确认依赖。可直接从用户明确给出的成果与约束进入，不要求 idea、story 或其他技能已经运行；优先接续已有阶段。按项目采用的规则版本和明确差异解释材料，版本未知或契约冲突按共同约定处理。

## 执行适配

按阶段计划 SOP 使用项目既有路径组织计划与 roadmap 关系。故事、技术方案或任务需要进一步展开时，可由当前执行者按相应 SOP 补充所需工作，不把兄弟技能的可用性或调用记录设为阶段规划前置；本次实际产出仍由授权范围决定。

## 输出

说明阶段成果、范围、退出条件、依赖和未决事项，给出实际计划与导航入口或讨论草案；计划成立与交付完成分别表述。
