# Compare

围绕项目中的真实选择形成有依据的比较。按[规则与方法读取](../../references/cli.md#规则与方法读取)先定位项目本地适用规范；包内[共同约定](../../tools/stonedocs/rules/docs/conventions.md)与[比较 SOP](../../tools/stonedocs/rules/docs/sop/compare.md)供未采用讨论或显式版本核对；调查、推荐和完成判断由这些文档维护。记录骨架见[比较输出结构与示例](../../tools/stonedocs/rules/docs/sop/compare.md#输出结构与示例)，资源版本见[固定快照清单](../../tools/stonedocs/rules/source.json)。

## 项目读取

定位问题、目标、约束，以及相关规格、架构、决定或研究，沿当前问题的链接读取。可从用户明确问题独立进入，不要求先有 idea 或阶段；不存在前序文件时不为流程补建。先识别讨论、只读调查或授权写回，按项目采用的规则版本和明确差异处理；版本未知或契约冲突按共同约定处理。

## 执行适配

按比较 SOP 调查，优先核对当前项目与一手来源；实验仅按实际授权进行。把可核对事实、实际观察、推断和推荐分开，保留会改变推荐的未知。比较不覆盖已有确认、不把推荐写成决定，也不因推荐新增实施承诺；若涉及规划，沿 Goal → Phase → Task 关联，Task 不脱离 Phase。

需要定位已有 Goal/Phase/Task 或读取项目 SOP 时，按[配套 CLI 用法](../../references/cli.md)使用只读入口；比较正文仍按本 SOP 组织，不把 CLI 检查当作调研或取舍。

## 输出

说明比较问题、判断依据、真实选项、推荐边界和未决选择。授权写回时复用同一问题的研究记录或所属阶段 research，讨论或只读请求只返回比较结果；通过内容和链接交接决定或后续工作，不依赖其他技能、CLI 或 Linear。
