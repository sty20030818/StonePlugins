# Task

拆分、接续、执行或移交已明确的阶段任务。先读取项目入口、[共同约定](../../references/docs-system/conventions.md)与[任务 SOP](../../references/docs-system/sop/task.md)；任务操作、移交及完成判断由这些文档维护。记录骨架见[任务输出结构与示例](../../references/docs-system/sop/task.md#输出结构与示例)，资源版本见[固定快照清单](../../references/docs-system/source.json)。

## 项目读取

沿项目入口定位所属阶段 plan、tasks，以及关联的 design、行为标准、决定和已有证据，使用项目现有路径。先识别本次是讨论、只读审查还是执行写回及实际授权；按项目采用的 SOP 版本和明确差异解释资料，版本未知或契约冲突按共同约定处理。

## 执行适配

按任务 SOP 使用项目已有工具和工程约束推进，所需能力以实际环境为准。需要验证时读取 [verify 入口](../verify/SKILL.md)，同一执行者可以连续完成；任务状态由当前执行者按共同约定和任务 SOP 写回，无需为状态循环调用技能。

## 输出

说明本次任务、实际产物、证据入口、当前状态和必要接续信息，项目记录按任务 SOP 写回对应所有者。
