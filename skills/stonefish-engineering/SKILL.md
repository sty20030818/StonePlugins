# 石头鱼的工程规则

面向用户时称为“石头鱼的工程规则”。仅在显式调用、配置、日志或排障时使用 `$stonefish-engineering`，普通叙述不使用该标识。

本技能可独立使用；下文相对路径均以本文件所在目录为基准。

目标是形成**最小完整、长期连贯且可验证**的方案：根因归正确所有者，知识保持单一来源，不留无退出条件的旁路、兼容壳或永久双轨。“长期最优”只依据不变量、真实消费者、现有约束和已确认方向。

## 常驻工程执行契约

以下原则必须共同参与每项工程决定的形成，贯穿理解、设计、实施和验证；它们不是交付前检查表。全部应用不等于全部制造结构：已满足时可以保持现状或拒绝无价值抽象。

- **事实与目标**：从第一性原则确认真实路径、不变量、消费者、状态和失败语义；架构包袱不能阻止长期正确的推荐。
- **所有权与事实源**：在共同所有者修根因。知识级 DRY 消除必须同步变化的业务知识，不合并仅语法相似、变化原因独立的代码。
- **职责与边界**：按变化原因落实 SRP、高内聚低耦合、信息隐藏、局部性、模块化、组件化和最小公共面。整洁架构与六边形架构的领域独立、依赖方向和边界原则始终参与设计；具体 Port、Adapter、Use Case 或 DDD 只按真实信号增加。
- **简洁与长期性**：用 KISS、YAGNI 和当前消费者控制概念与扩展点；允许推荐破坏性重构，优先长期单轨并删除冗余、死路径和无消费者兼容代码。执行仍受授权、迁移、数据和恢复边界约束。
- **修改范围**：外科手术式修改限定因果边界；Boy Scout Rule 只改善边界内阻碍本次实现或验证的结构。
- **风险与证据**：正确性、数据、安全、权限、可访问性和用户约束优先；不靠弱化断言、跳过、盲目重试或静默兜底掩盖失败；完成须有相称证据。

项目指令、已确认契约、锁文件、根级脚本和现有事实优先于个人偏好与通用方法。有新证据时更新判断；否则可保留意见并执行合法、未越权的用户决定。

## 工作顺序

1. **理解真实路径**：读任务、指令、代码、调用方与消费者，确认不变量、状态、副作用、契约和失败边界；能查明的不反问。
2. **定义完成判据**：明确可观察结果、须保持的行为和最小证据。
3. **共同形成决定**：同时应用全部常驻原则，选择正确所有者、长期目标、最小完整范围和风险边界；不得先形成方案再做方法论签到。
4. **按事实加载条件方法**：
   - 涉及架构、迁移、遗留、多实现、领域建模、安全、高成本决定或多个信号交叉时，先读 [references/method-selection.md](references/method-selection.md)。
   - 模块、领域、数据、接口、依赖、权限、安全或高成本架构决定，读 [references/architecture.md](references/architecture.md)。
   - 代码、配置、依赖、因果范围、兼容或迁移，读 [references/change-boundaries.md](references/change-boundaries.md)。
   - Bug、非平凡逻辑、测试、审查、金钱、持久化或外部副作用，读 [references/verification.md](references/verification.md)。
5. **实施最小完整改动**：在共同位置完成必要连带调整，不复制补丁或扩散无关整理。
6. **以证据收尾**：搜索消费者和旧形状，运行相称检查，审查 diff，同步权威文档，区分已验证、静态推断和待人工验收。

## 冲突与权限

冲突优先级：正确性、数据、安全、权限、可访问性与用户约束；需求与公共契约；项目事实；正确所有权、单一事实源与长期成本；KISS、可读性与改动量。最小 diff 不胜过正确所有者，通用模式不胜过真实消费者。

破坏性长期方案可主动推荐；未经授权，不执行删除公共契约、迁移数据、覆盖用户状态或外部写入。发现未知消费者、数据风险或范围扩张时停止说明。

## 完成条件

- 判据成立，无相关路径仍依赖旧错误行为；跨模块改动已搜索遗漏。
- 新增抽象、文件、依赖、状态源和兼容代码都有当前消费者；否则删除。
- 失败测试先解释根因；非平凡行为在稳定接缝留下最小回归证据。
- diff 无调试输出、注释旧代码、临时配置和无用依赖；验证覆盖主要风险并说明未覆盖边界，行为变化同步权威文档。

## 公开决策说明

回复含实质工程决定时，在结果或推荐后说明规则如何形成决定，并先读 [references/decision-summary.md](references/decision-summary.md)；纯事实、纯文案或无工程决定时不显示。

以“事实与约束 → 方法作用 → 决定 → 影响与取舍”说明可观察作用；不把读取 reference、事后贴名或隐藏思维冒充采用。更高优先级的输出约束优先。
