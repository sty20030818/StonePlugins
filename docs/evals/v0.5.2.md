- 环境：macOS，Node `24.16.0`、npm `11.13.0`、Codex CLI `0.154.0`。
- `npm run check` 通过：类型检查、重建、仓库校验和 10 项 Hook 测试，无跳过；官方 Skill 校验及 `git diff --check` 通过。
- 测试通过实际生成 Hook 核对四类 SessionStart、SubagentStart 的完整正文，覆盖含空格的独立包目录、环境变量和 cwd 无关性、元数据改写、非法输入、缺失或损坏资源、路径逃逸、超限失败和敏感输入不回显。
