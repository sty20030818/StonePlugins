# v0.12.5 版本验证

## 受检范围

有实际下一步时，工程小结整条省略可选想法，包括标题、正文和附注。在完整工程核心与逐轮提醒中明确两种结尾的互斥关系。没有实际待办时，可按任务事实提供一个值得考虑的延伸。收尾时只汇报结果。关联 [TIMING-1](behavior-cases.md#timing-1-工程回复与接续) 和 [0.12.4 原生会话观察](v0.12.4.md#正式发布与安装)。

## 候选检查

2026-11-27，`npm run check` 的 57 项测试通过。四个临时只读 CLI 样例均通过，涵盖实际下一步优先、仅有可选想法、确实收尾和等待授权。候选逐轮提醒为 299 个 UTF-8 字节。

在原生 CLI 输入框回放 0.12.4 失败的交接样例。两侧分别显式提供对应版本 Hook 生成的完整核心和提醒，关闭自动加载，核对会话实际收到指定文本。0.12.4 对照在下一步要点里保留了可选想法。0.12.5 候选只报告复核动作和接手人，全文未出现该想法。候选同时通过只有可选想法及确实收尾的两个原生输入反例。候选规则的真实自动送达在正式安装后另验。

## 正式发布与安装

2026-11-27，提交 `7af458e` 通过本地发布门禁。Node.js 22.18.0 和 24 的[主分支 CI](https://github.com/sty20030818/StonePlugins/actions/runs/45973177284)和[标签 CI](https://github.com/sty20030818/StonePlugins/actions/runs/45973177297)均通过。北京时间 17:24 用 `gh` 发布 [v0.12.5 正式 Release](https://github.com/sty20030818/StonePlugins/releases/tag/v0.12.5)，按最新正式版回读。

本机从 GitHub 固定标签安装并启用 0.12.5，81 个安装文件的内容和可执行位均与该标签归档一致。新 CLI 进程发现 11 个技能。三个 Hook 已获授权并在原生界面逐项审核和信任。直接运行已安装脚本时，SessionStart 和 SubagentStart 各返回 7,777 字节完整核心，UserPromptSubmit 返回 299 字节提醒。

四个全新原生 CLI 会话均收到与安装脚本逐字一致的完整核心和提醒。两次存在真实后续的交接都只列了复核动作和接手人，全文省略可选想法。无待办的延伸样例只列可选想法，收尾样例只列核对结果。四次实测均符合预期。
