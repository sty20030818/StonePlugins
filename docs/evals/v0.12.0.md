# v0.12.0 版本验证

## 受检范围

本次调整 engineering 技能和每轮提醒。日常工程结果采用独立的 Markdown 三级标题和无序列表，存在有序流程时标明当前位置，有实际接续时单列「➡️ 下一步」并明确接手人。需用户作决定时单列引用块。评测使用 [TIMING-1](behavior-cases.md#timing-1-工程回复与接续)。配套 StoneDocs CLI 为 0.3.0，规则与 Linear 指南的固定来源见[v0.11.0 版本验证](v0.11.0.md#固定构建与包内检查)。

## 工作树检查

2026-11-27，在 StonePlugins 仓根分别向生成的 Hook 提交 SessionStart、SubagentStart 和 UserPromptSubmit。前两项各输出 7,324 个 UTF-8 字节，正文含三级结果标题和「➡️ 下一步」约定；每轮提醒为 297 个 UTF-8 字节。以上是工作树脚本的实际输出。个人安装后的观察重点是新对话能否给出真实标题、流程位置，以及有接续时由谁执行下一步。
