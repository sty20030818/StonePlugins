本机已更新启用 v0.7.0，35 文件集合与字节匹配 tag，七项正式入口已发现。三个新路径 Hook 经正式接口重新信任，最终仍启用且 trusted；本轮共 30 次实际送达完成。临时样例项目信任已精确清理，最终配置只保留目标 marketplace ref 和三个获准信任摘要变化，个人 AGENTS 及其他配置保持。

实际桌面内置 CLI 0.166.0-alpha.6 使用 gpt-6.1-sol / ultra 完成 11/11 个正式插件用例，两组运行器退出码均 0；234 项事实检查与逐例语义审阅通过。三个自然语言独立例实际读取各自正式 SKILL 与同包 SOP，不要求前序调用或阶段；六步原生注入均匹配缓存，按 story → plan → design → task → verify → review 读取文件接续。文学 story 与纯视觉 design 两个负例未误入目标工作流。

样例 task 保留原四项断言并补一项内部 Tab 回归：旧实现真实测试退出 1（2 通过、3 失败），修正后退出 0（5/5 通过）。verify 复用匹配证据，review 先保存并读回判断，再完成原地归档。独立使用指资料与调用前置独立，本轮七项技能同时安装可见，没有项目级候选副本。

实际工具失败、临时上下文协作继承失败与恢复、审计白名单修正及环境检查脚本偏差均保留在[完整验收档案](https://github.com/sty20030818/StoneDocs/blob/b02b5fbb98c9526d9180b78f4812213517227563/docs/phases/p012-planning-skills-release/verification.md)，没有重跑模型修饰结果。另有独立 design 输出首链接含 U+200C 的非阻断文本观察；本轮未验收 UI 点击/渲染。有限样例不证明其他措辞、路线、模型、平台或长期可靠性。P007 候选历史不替代本版正式验证。
