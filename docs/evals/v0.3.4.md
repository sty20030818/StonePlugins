## 无效夹具记录

最终评分不包含以下运行：

1. `ROUTING-1`、`TIDY-2`、`MIGRATION-2` 的初始提示要求“另附简短评测报告”。即使结果正确，仍可能污染路由，因此全部重跑。
2. `ROUTING-2` 首次也包含该元措辞，Agent 因而合理读取了 `methodology-index.md`；这是夹具污染，不是规则误路由。
3. `ROUTING-2` 第二次要求“只诊断问题，不修改代码”，Agent 读取了 `verification.md`，但没有读取只在修改前触发的 `change-boundaries.md`；该提示改变了原案例的修改语义。
4. `MIGRATION-2` 有一次干净变体只要求“给出迁移决策”。Agent 未读方法论索引但仍做出正确的 Parallel Change 决策；这证明索引不是正确决策的强制前置。最终提示增加中性的“比较可行的迁移策略”，用于验证方法比较时的索引路由。

最终提示均删除元评测措辞，并保持案例要验证的任务语义。后续评测不得在任务正文中出现“评测、期望、案例 ID”等路由线索；修改提示语义时必须标记 `fixture changed`。
