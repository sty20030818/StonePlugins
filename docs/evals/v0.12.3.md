# v0.12.3 版本验证

## 受检范围

工程小结每组列出事实或动作要点。遇到拍板时给推荐和各选项的主要影响，可以写在列表或引用块里，同一个决定只问一次。有实际后续时列出具体下一步和接手人。提示词按用户明确请求提供。

## 候选检查

2026-11-27，`npm run check` 的 57 项测试通过。以 Codex CLI 0.171.0 在四个独立的临时会话中按 [TIMING-1](behavior-cases.md#timing-1-工程回复与接续) 实跑。运行时只注入候选的完整工程核心。

| 用例 | 观察 |
| --- | --- |
| 交接 | 分别列出本轮成果、实际下一步和前端接手人。 |
| 独立布局拍板 | 给出两个选项的影响及推荐，只问一次。 |
| 拍板本身是接续 | 收尾成果和发布时间均有要点，交代两个时段的影响、推荐和执行人。 |
| 本轮已收尾 | 只列实际成果和要点。 |

四个样例均通过，都没有附提示词模板。这批验证的是候选在 CLI 中的实际回复。桌面端送达和格式另行验证。
