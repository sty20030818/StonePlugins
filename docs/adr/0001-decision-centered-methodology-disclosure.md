# 以工程决策为单位说明实际采用的方法论

用户需要判断工程决策是否合理，而不是查看方法名清单。石头鱼的工程规则按独立决策组织“本次决策与方法论”：仅在方法论、工程判断或用户明确约束实际改变所有者、范围、契约、风险处理、兼容策略或验证方式时展示，并说明准确分类、适用事实、具体作用和情境化影响；方案阶段使用“预期影响、验证计划”，交付阶段使用“方案影响、验证证据”，再按决定复杂度自适应展开 Markdown。大量决定先用紧凑索引覆盖，只展开高风险、需确认或有真实竞争的项；更高优先级的输出约束始终优先。运行时契约只由核心 `SKILL.md` 持有，本 ADR 记录取舍而不复制模板。这样提高了决策透明度和学习价值，代价是核心 Skill 与评测必须持续维护触发准确性并避免机械套模板。
